# O2 桌面计时入口与面板接线

日期：2026-11-17；起点dev de93021。增量自评；结论：自动化验证通过，原生端到端未完成，O2未验收。

新增timer_commands.rs，在现有Workspace内持有TimerClock，与Store共用固定顺序的锁：先存储再时钟；计时命令/查询均在spawn_blocking内串行执行。前端timer_action不收时间戳，操作请求携带任务或会话版本。start先核对无活动会话和任务版本；非start先核对活动会话ID、版本、状态。Store仍校验叶任务、归档与唯一活动会话；任务状态暂不自动随会话变更。

时钟由SystemTime墙钟与Instant单调计时交叉检查。墙钟回退、两者差值超过2秒或采样间隔超过30秒时拒绝确认开放区间，转recovering；下一次查询显示保守恢复状态。该阈值是首轮保守策略，长时间UI挂起也会触发，尚未按真实办公体验调优。不是锁屏/休眠系统事件集成，不宣称所有睡眠时钟行为已验证。开放区间暂计与已确认分列，无心跳可信前缀；中断时整个开放区间保留待确认。

工作区创建/打开前在workspace.lock上获取标准库文件独占锁，句柄保留到Workspace销毁；失败拒绝打开。取得所有权后执行recover_interrupted_timers，再接受命令。锁只约束本版本遵循同协议的进程，旧小样不遵守该锁，不能同时运行新旧版本共享验证目录。

Store增加active_timer查询及open_since_ms用于后端计算暂计，不增加第二份计时事实。右侧TimerPanel每秒读取同一后端，轮询和用户操作不重叠，序列号阻止过期轮询覆盖新状态。面板一直挂载，切换事务/便签视图仍采样；刷新关闭、整个应用被系统挂起则进入保守恢复策略。有任务草稿时禁用计时动作，避免草稿和任务状态冲突。

面板支持：选择Ready/Doing任务开始；暂停/继续/结束；显示已确认与暂计；结束中断会话释放占用，未知证据仍保留。结束后活动查询为空，当前没有已结束会话列表、今日聚合或历史修正界面，待确认历史仍存储但未提供专门历史检索入口。
