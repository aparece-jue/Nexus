# O1 子任务、标签、标签搜索及任务编辑

日期：2026-11-17；起点 dev cea3242。增量自评，结论：自动化验证通过，原生验证仍不完整。

## 功能与契约

create_task 追加可选 parent_id 和默认空 tags，旧 IPC 调用保持兼容；创建父子关系与标签在同事务内完成。Rust直接调用方已同步传参，不维护第二套创建入口。任务可选择父任务，界面显示父任务名称；当前为带父关系的列表，还没有折叠树视图。

update_task 保存标题、项目、父任务、标签、归档状态，使用 expected_row_version 校验；标签与任务字段同事务提交。便签来源版本保留不变。编辑失败保留表单；编辑中禁用其他任务编辑入口，避免切换丢失草稿。

父子规则：父任务必须存在、与子任务同项目（无项目也须一致）；拒绝自引用和祖先循环；不能向终结态或归档父任务挂接活动子任务。父任务变更项目时，只要子任务仍属旧项目便拒绝，避免自动移动整树。父任务有未归档子任务时不能归档，有未完成/未取消的活动子任务时不能结束（Done或Cancelled）。父任务结束后，子任务重开需先显式重开父任务。恢复子任务也会重新校验父任务状态。这些是Nexus新增层级约束，Worktrace状态表本身不变。

任务最多20个输入标签，每个归一化后1–40字符；去首尾空白、可选前导#，使用Rust Unicode小写化并去重。标签以task_tag关联表为唯一事实，编辑即替换该任务标签，不自动继承父任务标签。

list_tasks 增加可选 query：tag精确匹配、text标题包含、archived归档范围；省略时仍返回未归档任务。tag与text组合为AND。标题搜索沿用SQLite lower（ASCII大小写折叠，中文可原文匹配）；标签通过Rust归一化保持大小写规则一致。不宣称多标签AND/OR或全文搜索已实现。父任务候选也复用list_tasks默认查询，没有另建搜索服务。

schema3→4新增parent_id、archived、task_tag与索引；先生成before-schema-4.db一致快照，不覆盖已有快照。迁移前数据库快照需配合原blobs恢复，不等于独立完整备份。
