# 办公版三栏界面增量

日期：2026-11-17；起点 dev bc62239。依据用户参考截图，独立实现导航、任务列表、详情三栏。结论：本增量构建和前端验证通过，原生验收未完整。

左侧：所有任务、收集箱、归档、项目和现有标签。中间：任务创建、组合搜索、父子列表和折叠控制。标签入口调用现有list_tasks query；项目/收集箱只过滤已加载视图，不另建业务数据。筛选隐藏父任务时，命中的子任务提升为当前结果根节点，避免漏掉搜索结果。右侧：选中任务后编辑字段、父关系、标签、归档状态，原状态动作和来源入口集中在详情。

详情编辑保持现有显式保存；草稿未保存时阻止状态变更和选择另一条任务，保存失败保留草稿。折叠不改变任务数据或详情。顶部切换事务/便签，两个视图保持挂载，已有便签和任务草稿不因导航卸载。便签仍使用原列表/编辑布局，本次尚未统一为任务式三栏。未增加“今天”入口，因为截止日期等尚未实现，不显示虚假能力。

没有修改Rust接口、数据库或状态规则，未安装依赖。CSS增加桌面三栏和窄屏布局，采用低饱和灰紫配色；没有复制参考产品素材。
