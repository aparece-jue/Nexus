# ADR 0004：首版不做应用级加密

日期：2026-11-03｜状态：accepted（用户明确选择）

## 决策

首版不做应用级加密，优先完成本地业务闭环。SQLite、正文、附件及初期导出备份均不宣称加密；不引入密码界面、密钥恢复或加密数据库驱动。不因该选择允许自动上传或扩大 Agent 权限。

## 必须保留

备份一致性、文件哈希校验、迁移前保护、未来版本拒写、恢复预检、路径范围检查、凭据单独保存及日志脱敏仍是要求。哈希用于完整性检查，不提供保密性，也不等同于抵抗恶意篡改的认证签名。

界面/使用说明明确本地数据未加密，同账户其他程序可能读取；不假定系统已经启用磁盘加密。用户自行决定存入何种真实资料，测试继续使用合成数据。

## 后续演进

如用户后续要求加密，先确认威胁范围、数据库/附件/备份边界及密钥遗失策略，再进行带备份的显式格式迁移；不提前设计无使用方的通用密码抽象。

## 下一步

继续持久工作区及 schema 版本保护，接入既有对象/工时契约和完整闭环。此决定解除了加密选择阻塞，但未代替桌面实测、备份恢复和领域验收。
