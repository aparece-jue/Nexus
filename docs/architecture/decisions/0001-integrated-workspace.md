# ADR 0001：采用一体化个人工作平台

日期：2026-11-02｜状态：accepted（产品架构方向）

## 背景

用户明确认为统一来源更符合一体化方案，选择由 Nexus 统一管理知识、事务、设计与画布。此前讨论过以 Obsidian 等外部应用构成工作枢纽的路线，现不作为主路线。

## 决策

Nexus 是核心业务对象的管理与编辑入口，各视图引用稳定对象 ID。SQLite 保存结构化事实与版本索引，本地不可变文件保存正文和附件；应用协调一致性。采用成熟组件嵌入编辑、画布和统计能力。

外部知识工具定位为参考和导入来源；专业工程软件通过文件、版本与证据衔接。具体依赖选择未因此自动批准。

## 权衡与验证

减少跨应用同步与来源冲突，代价是自研编辑交互、统一模型和迁移能力增加。以分阶段交付控制范围；当前仅完成设计，尚无实现验证。

当必要专业格式无法维护、外部编辑成为刚需或开发成本显著超出资源时重新评估；通过新增 ADR 记录变更，不覆盖此记录。
